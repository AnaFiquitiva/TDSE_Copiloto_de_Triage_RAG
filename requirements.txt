# Este prototipo funciona con la biblioteca estandar de Python 3.10+
# (no requiere dependencias externas de terceros), para que el pipeline
# offline sea reproducible sin instalar nada.
#
# El backend LLM opcional (Gemini, ver README.md "Backend LLM opcional")
# tambien usa solo la biblioteca estandar (urllib) en vez del SDK oficial
# google-generativeai, a proposito, para no romper esta politica de cero
# dependencias. Si en el futuro se prefiere el SDK oficial (mas features,
# mas mantenimiento upstream) o un modelo de embeddings local (p. ej.
# sentence-transformers), agregar esa dependencia aqui.
#
# La interfaz web opcional (web/backend/, web/frontend/, ver README.md
# "Interfaz web") SI tiene dependencias de terceros (FastAPI, React), pero
# viven aisladas en sus propios requirements.txt/package.json y no afectan
# a este archivo ni al pipeline principal.
